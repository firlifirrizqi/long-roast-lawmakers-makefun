# The Long Roast: Lawmakers and the File They Cannot Convert

One-sentence satirical entry for the [Make.fun bounty](https://make.fun/bounty/u-swift-raven-16-the-long-roast-lawmakers-and-the-f3a3bdf7) of the same name: a lawmaker drafting an AI safety bill who cannot manage the most basic file conversion himself, so his aide has to do it — and the workaround only gets more absurd from there.

## The line

> The senator drafting the AI safety bill had his aide convert the draft to PDF, print it, scan it back in, and email it to himself as a photo of the screen.

## How it works

`main.py` writes that single line (155 characters, within the 320-character limit) to `/output/entry.txt`. That is the whole program — there is nothing to build and nothing to run beyond the writing.

## Run

```sh
python3 main.py
```
